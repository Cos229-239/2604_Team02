### Project Setup

Navigate to the app folder:

cd app

Install dependencies:

npm install

Run the development server:

npm run dev

----------------------------------------------------------------

Git Workflow

We are using a branch-based workflow to keep development organized and stable.

Branches
main → stable version of the project
dev → integration branch for team features
yourNamePersonal → your personal working branch

----------------------------------------------------------------

How to Work on the Project

1 Fetch the latest changes:
git fetch origin

2 Switch to your personal branch:
git checkout yourNamePersonal

3 Make your changes and commit:
git add .
git commit -m "Your message here"

4 Push your branch:
git push origin yourNamePersonal

----------------------------------------------------------------

Merging to Dev
Only merge your work into dev when:
The project runs without errors
Your feature is complete or stable

Merge process:
Pull latest dev
Merge into your branch (to avoid conflicts)
Then merge your branch → dev

----------------------------------------------------------------

Important Rules
Do NOT push directly to main
Do NOT push broken code to dev
Always work from your personal branch
Commit meaningful changes
